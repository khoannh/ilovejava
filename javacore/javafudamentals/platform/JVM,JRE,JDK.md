We need to know the flow of program when we click RUN:

```text
+-------------------+       javac       +-------------------+       JVM        +-------------------+      Chạy      +----------------+
|  Chương trình Java | ----------------> |   Java Bytecode   | --------------> |       Mã máy      | ------------> |    Kết quả     |
|     (.java)       |   (Biên dịch)     |      (.class)     |  (Thông dịch)   |    (010101...)    |   (Phần cứng)  |                |
+-------------------+                   +-------------------+                 +-------------------+                +----------------+
``` 
Explain:
- Chương trình Java: src code (file .java) written by dev
- javac (java compiler) will compile code .java into Java bytecode .class
- From java bytecode, JVM will convert it to machine code, suitable for OS.
- When we have machine code, CPU will execute every machine code line to produce the final output.

# JVM #
**JVM (Java Virtual Machine**) is a virtual machine, used to convert java bytecode in .class file to native machine code so that CPU can understand and execute.

JVM makes Java "write once, run anywhere". Because if we have java bytecode, we can run this program on any OS by using JVM of this OS to convert into machine code without re-compiling.

`What is Java bytecode?` It is the intermediate instruction set generated by Java compiler (javac). It is stored in .class file and JVM will use it to convert into machine code of any OS.


# JRE #
**JRE (Java Runtime Environment)** is a environment that provides everything needed to run Java application. It runs program only, cannot compile.

JRE has 2 members:
- JVM 
- libraries set: it is a set that contains many core libraries of Java like String, Syste or Collection, Time,... They are not Wu-kong, not be born from ice or available something. Java write all of them and add into 1 module name: *java.base*. We can open this package and will see java.lang, java.utl,... For example `System.out.println` is used for print something. It quite easyly to use but if it is not available, we will write many lines of codes to write something only. :)

JRE is essential thing we must have if we want to run Java application. For example, we want to play Minecraft or some desktop application written by Java, we have to download JRE, but nowadays JRE is contained by JDK, and we just need to download JDK.


# JDK #
**JDK (Java Development Kit)** is a minimum software we need to compile and run Java program.

4 basic commands of JDK:
- `javac`: compile src code, converting .java files into .class bytecode files.
- `java`: execute or run the program 
- `jar (java archive`: package .class bytecode files, images, css and other resources into a single .jar file for easily distribution.
- `javadoc`: generate documentation

=> It actually is 4 executable files to match each specific operating system.
For example, on Windows, they are .exe like javac.exe, java.exe, etc. or on Linux or Ubuntu, they are binary files.

`Why we call JDK is minimum software?`
Because of programing by Java is writing, compiling and running Java code.
JDK also has 2 components: JRE and development tools (contains javac, debugger, etc). If we have JDK, we can use Notepad to write code, then using terminal or command prompt, using 2 first commands (javac and java) to create the output.

=> JDK is used to develop Java program.
