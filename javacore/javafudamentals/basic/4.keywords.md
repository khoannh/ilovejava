Java keywords are reserved words (những từ dành riêng) with predefined meanings, cannot be modified.

According to last version of Java, we have 68 keywords.

# Data Type Keywords #

| Keyword | Usage |
| :--- | :--- |
| `boolean` | Defines a variable that holds `true` or `false`. |
| `byte` | Defines an 8-bit signed integer. |
| `char` | Defines a 16-bit Unicode character. |
| `short` | Defines a 16-bit signed integer. |
| `int` | Defines a 32-bit signed integer. |
| `long` | Defines a 64-bit signed integer. |
| `float` | Defines a 32-bit floating-point number. |
| `double` | Defines a 64-bit floating-point number. |
| `void` | Specifies that a method does not return any value. |

---

# Control Flow Keywords #

| Keyword | Usage |
| :--- | :--- |
| `if` | Executes code when a condition is `true`. |
| `else` | Defines an alternate block when an `if` condition is `false`. |
| `switch` | Selects one block of code among multiple options. |
| `case` | Defines an individual branch in a `switch` statement. |
| `default` | Defines the block executed if no `case` matches. |
| `for` | Starts a `for` loop. |
| `while` | Starts a `while` loop. |
| `do` | Starts a `do-while` loop. |
| `break` | Terminates the nearest loop or `switch`. |
| `continue` | Skips to the next iteration of a loop. |
| `return` | Exits from a method and optionally returns a value. |

---

# Exception Handling Keywords #

| Keyword | Usage |
| :--- | :--- |
| `try` | Defines a block of code to test for exceptions. |
| `catch` | Defines a block to handle exceptions thrown by `try`. |
| `finally` | Defines a block that always executes after `try` and `catch`. |
| `throw` | Used to manually throw an exception instance. |
| `throws` | Declares the exceptions a method can throw. |
| `assert` | Tests assumptions during program execution for debugging. |

# Object-Oriented Keywords # 

| Keyword | Usage |
| :--- | :--- |
| `class` | Declares a class. |
| `interface` | Declares an interface. |
| `extends` | Indicates inheritance from a superclass. |
| `implements` | Indicates that a class implements an interface. |
| `new` | Creates new objects in the Heap memory. |
| `this` | Refers to the current object instance. |
| `super` | Refers to the superclass of the current object. |
| `abstract` | Declares a class or method that must be implemented in a subclass. |
| `final` | Prevents inheritance (class), overriding (method), or modification (variable). |
| `static` | Declares class-level variables or methods shared across instances. |
| `sealed` | Restricts which classes or interfaces can extend or implement it. |
| `permits` | Specifies the exact subclasses allowed to extend a sealed class. |
| `enum` | Declares a fixed set of named constants. |
| `record` | Declares an immutable data carrier class (Java 16+). |
| `instanceof` | Checks whether an object is an instance of a specific type or interface. |

| Keyword | Usage |
| :--- | :--- |
| `public` | Accessible from anywhere in the program. |
| `protected` | Accessible within the same package or by subclasses in other packages. |
| `private` | Accessible only within the same class. |

# Reserved Identifier Keyword in Java #

| Keyword | Since | Usage & Rules |
| :--- | :---: | :--- |
| `_` (underscore) | Java 9+ | Reserved as a keyword; cannot be used as a standalone identifier (variable, method, or class name). Starting in Java 21+, it acts as an **unnamed variable / unnamed pattern** to mark intentionally unused parameters. |

> [!WARNING]
> * `int _ = 10;` gây lỗi biên dịch từ Java 9 trở đi.
> * Các biến chứa ký tự gạch dưới kết hợp chữ/số khác (ví dụ: `_count`, `MAX_VALUE`) vẫn hợp lệ hoàn toàn.

# Contextual Keywords in Java #

> [!NOTE]
> **Contextual keywords** (hay restricted keywords) chỉ có ý nghĩa đặc biệt trong một ngữ cảnh cú pháp nhất định (như khai báo module, sealed class, hoặc record). Ở mọi vị trí khác, chúng vẫn có thể được dùng làm tên biến hoặc tên phương thức bình thường (để đảm bảo tương thích ngược).

| Keyword | Introduced | Primary Context | Usage |
| :--- | :---: | :--- | :--- |
| `module` | Java 9 | Module declaration (`module-info.java`) | Declares a named module. |
| `requires` | Java 9 | Module declaration | Specifies a module dependency needed by the current module. |
| `exports` | Java 9 | Module declaration | Makes a package accessible to other modules. |
| `opens` | Java 9 | Module declaration | Opens a package for deep reflection at runtime. |
| `uses` | Java 9 | Module declaration | Specifies a service interface that the module consumes via `ServiceLoader`. |
| `provides` | Java 9 | Module declaration | Declares that the module provides a service implementation. |
| `with` | Java 9 | Module declaration | Specifies the implementation class used in a `provides` statement. |
| `to` | Java 9 | Module declaration | Restricts `exports` or `opens` to a specific list of recipient modules. |
| `transitive` | Java 9 | Module declaration | Causes an imported module dependency to be automatically read by modules reading this module. |
| `open` | Java 9 | Module declaration | Creates an open module (allows runtime reflective access to all packages). |
| `record` | Java 16 | Class declaration | Declares a concise, immutable data-carrier class. |
| `sealed` | Java 17 | Class / Interface declaration | Declares a class or interface whose subclasses are strictly controlled. |
| `permits` | Java 17 | Class / Interface declaration | Explicitly lists the subclasses allowed to extend a `sealed` class. |
| `non-sealed` | Java 17 | Subclass declaration | Re-opens a subclass of a `sealed` class to allow unrestricted inheritance. |
