# INPUT # 
(System.in) => Input (keyboard) => Receiving data from the user.

=> Usually using Scanner class to take the console input.
1. import Scanner class `import java.util.Scanner;` 
2. init Scanner object `Scanner sc = new Scanner(System.in); ` => sc just is name, you can assign other name.
3. taking input `sc.nextInt()` => there are many Scanner methods to taking other data types.

### Common `Scanner` Methods in Java

| Method | Used For | Example |
| :--- | :--- | :--- |
| `nextInt()` | Integer (`int`) | `int n = sc.nextInt();` |
| `nextLong()` | Long integer (`long`) | `long n = sc.nextLong();` |
| `nextFloat()` | Single-precision floating point (`float`) | `float n = sc.nextFloat();` |
| `nextDouble()` | Double-precision floating point (`double`) | `double n = sc.nextDouble();` |
| `nextBoolean()` | Boolean (`true` / `false`) | `boolean b = sc.nextBoolean();` |
| `next()` | Single word/token (delimited by whitespace) | `String s = sc.next();` |
| `nextLine()` | Complete line (reads until newline `\n`) | `String s = sc.nextLine();` |

=> Divide into 2 groups:
- from nextInt() to next(): dừng lại khi gặp whitespace (tab, space, enter) và bỏ lại nó trong bộ nhớ đệm.
- nextLine(): gom toàn bộ mọi thứ trên 1 dòng và chỉ dừng lại khi gặp dấu Enter (\n) và nhận luôn phím Enter đó.

=> Vì thế nên gây ra 1 problem: nếu dùng nextLine() ngay sau các next.. trong nhóm 1 thì sẽ bị thằng nextLine() sẽ bị skip.

`int age = sc.nextInt();
String name = sc.nextLine();`
=> Khi in ra chắc chắn thằng name sẽ bị trống thằng age bỏ lại dấu enter, ngay sau đó thằng nextLine gặp dấu Enter tưởng người dùng đã nhập xong nên chốt deal luôn.

**Cách khắc phục:** dùng sc.nextLine() để consume (nhận, tiêu thụ) đi dấu Enter (\n) còn thừa trong bộ nhớ đệm.
`int age = sc.nextInt();
sc.nextLine();
String name = sc.nextLine();`


# OUTPUT #
(System.out) => display normal information on the console.
There are 3 commonly used methods:
- `System.out.print()` : print without adding new line.
- `System.out.println()` : print and moves the cursor to the new line.
- `System.out.printf()` : print when formatted output is required.


```
import java.util.Scanner; 

class GFG{
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); 

        System.out.print("Enter name: ");
        String name = sc.nextLine();

        System.out.print("Enter age: ");
        int age = sc.nextInt();

        System.out.print("Enter marks: ");
        double marks = sc.nextDouble();

        System.out.println("\nStudent Details");
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("Marks: " + marks);

        sc.close();
    }
}
```
