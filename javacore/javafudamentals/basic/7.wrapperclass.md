# Definition #
Wrapper classes are classes provided by Java to represent primitive values as Objects.

`Why wrapper classes are needed ?`

`Answer: ` Because:
- Collections only work with Object.
- Object supports null value when primitives do not.
- Can use some utility method of objects like toString(), compareTo(),...

#### Primitive vs. Wrapper Mapping Table
| Primitive Type | Wrapper Class | Memory Location | Default Value |
| :--- | :--- | :--- | :---: |
| `byte` | `Byte` | Heap | `null` |
| `short` | `Short` | Heap | `null` |
| `int` | `Integer` | Heap | `null` |
| `long` | `Long` | Heap | `null` |
| `float` | `Float` | Heap | `null` |
| `double` | `Double` | Heap | `null` |
| `char` | `Character` | Heap | `null` |
| `boolean` | `Boolean` | Heap | `null` |


=> Tương ứng với 8 kiểu primitives thì sẽ có 8 thằng Wrapper tương ứng.

=> **Ứng dụng:** Wrapper thường ít thấy dùng trong Java core, các lập trình console, nhưng xuất hiện nhiều trong OOP, backend Spring Boot, đặc biệt là Entity, DTO, JSON,...

**2 mechanics:**
- Auto boxing: primitive -> wrapper class. 
- Unboxing: wrapper class -> primitive

**3 method cần phải nhớ với Wrapper class:**
- từ String -> primitives: parseXXX(String). Ví dụ: int a = Interger.parseInt("100");
- từ String hoặc primitives -> wrapper object: valueOf(). Ví dụ: Integer obj = Intger.valueOf(100); hoặc Integer obj = Integer.valueOf("100"); 
- từ wrapper object -> primitive: xxxValue(). Ví dụ: obj.intValue(); 
=> Hiện nay thì thằng xxxValue() ít được dùng rồi vì Java cho phép chuyển thẳng.
``` 
Ví dụ: Integer a = 10; // auto boxing, đây là kiểu mình thường thấy nhất, viết như khai báo biến bình thường vậy nhưng thuwjc
int b = a.intValue() // như này là manual unboxing
int b = a; // JVM tự unboxing ngầm 
```
=> Chỉ có thằng xxxValue() mới bị nerf thôi chứ thằng valueOf() vẫn dùng bình thường vì thằng này nó còn phải chuyển từ String sang wrapper nên không thể nào:
```
Ví dụ: Integer a = Integer.valueOf("123"); // ĐÚNG
Integer a = "123"; // SAI 
```

### Complete Type Conversion & Boxing Summary Table

| Chiều chuyển đổi | Đoạn mã ví dụ | Thuật ngữ chuẩn (Technical Term) |
| :--- | :--- | :--- |
| `int` $\rightarrow$ `Integer` (tự động) | `Integer a = 10;` | **Autoboxing** |
| `int` $\rightarrow$ `Integer` (thủ công) | `Integer a = Integer.valueOf(10);` | **Manual Boxing** |
| `Integer` $\rightarrow$ `int` (tự động) | `int b = a;` | **Unboxing** |
| `Integer` $\rightarrow$ `int` (thủ công) | `int b = a.intValue();` | **Manual Unboxing** |
| `String` $\rightarrow$ `Integer` | `Integer a = Integer.valueOf("10");` | **String Parsing / Object Factory** |
| `String` $\rightarrow$ `int` | `int a = Integer.parseInt("10");` | **String Parsing** |
| `Integer` $\rightarrow$ `String` | `String s = a.toString();` | **String Conversion** |
| `int` $\rightarrow$ `String` | `String s = Integer.toString(10);` <br> hoặc `String.valueOf(10);` | **String Conversion** |

**Quy tắc:**
- Autoboxing/Unboxing chỉ là giữa primitive và wrapper, thằng String không liên quan gì cả. Cơ chế của chúng là giảm đi sự dài dòng của syntax, còn nếu mình viết đầy đủ các hàm thì đó sẽ là manual.
- Từ String qua bất kì thằng nào cũng đều phải thủ công, không có tự động.


**Trường hợp đặc biệt:** unboxing giá trị null
```
Ví dụ: 
Integer a = null;
int x = a; // NullPointerException

```
