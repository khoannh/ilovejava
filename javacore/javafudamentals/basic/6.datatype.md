`Why do we need data type?`

`Answers:`There are 3 main reasons:
- Memory allocation: tell the JVM and OS exactly how many bytes of RAM to allocate for the variable.
- Defines which operations are supported for this type.
- Variable will have default value when not initialized.

`Syntax: dataType varName = value;`

2 types of data type:
- Primitive data type: store simple value in memory.
- Non-primitive (Reference) data type: store references to objects.

# Primitive data type #
There are 8 types:

| Type | Description | Size | Range | Default | Example |
| :--- | :--- | :---: | :--- | :---: | :--- |
| `boolean` | Logical values | JVM-dependent* | `true` or `false` | `false` | `true`, `false` |
| `byte` | 8-bit signed integer | 1 byte (8 bits) | -128 to 127 ($-2^7$ to $2^7 - 1$) | `0` | `10`, `-50` |
| `short` | 16-bit signed integer | 2 bytes (16 bits) | -32,768 to 32,767 ($-2^{15}$ to $2^{15} - 1$) | `0` | `2000`, `-300` |
| `char` | 16-bit Unicode character | 2 bytes (16 bits) | 0 to 65,535 ($0$ to $2^{16} - 1$) | `'\u0000'` | `'A'`, `'\u0041'` |
| `int` | 32-bit signed integer | 4 bytes (32 bits) | -2,147,483,648 to 2,147,483,647 ($-2^{31}$ to $2^{31} - 1$) | `0` | `1000`, `-500` |
| `long` | 64-bit signed integer | 8 bytes (64 bits) | $\approx \pm 9.22 \times 10^{18}$ ($-2^{63}$ to $2^{63} - 1$) | `0L` | `123456789L` |
| `float` | 32-bit IEEE 754 floating point | 4 bytes (32 bits) | $\approx \pm 3.4 \times 10^{38}$ (~6–7 decimal digits precision) | `0.0f` | `3.14f` |
| `double` | 64-bit IEEE 754 floating point | 8 bytes (64 bits) | $\approx \pm 1.8 \times 10^{308}$ (~15–16 decimal digits precision) | `0.0d` | `3.14159d` |


### Explain ###
``` 
Đơn vị nhỏ nhất của bộ nhớ là bit, có giá trị là 0 hoặc 1.
1 byte= 8 bits. 1 byte chính là 1 ô trong bộ nhớ RAM. Mình cứ tưởng tượng RAM nó chia đều thành cả đống ô, mỗi ô có 1 địa chỉ duy nhất, thì trong đó 1 ô có dung lượng là 1 byte.
Tương ứng với từng kiểu dữ liệu, JVM sẽ tính toán cấp phát bao nhiêu ô cho 1 biến đó dựa trên size của data type.
Ví dụ 1: byte a = 10;
Ta có 1 byte tương ứng với 1 ô nhớ, suy ra JVM chỉ cần cấp 1 ô cho biến a và chứa số 10 ở trỏng.
Ví dụ 2: int age = 14;
Ta có 1 int = 4 bytes. Suy ra JVM phải cung cấp 4 ô liền kề nhau, gộp lại để chứa số 14 cho biến age.
  
```
### Note ###
```
- integer types (byte, short, int, long): đối với long thì đằng sau số phải có chữ l hoặc L => số nguyên mặc định là kiểu int, default value = 0.
- floating-point types (float, double): đối với float thì đăằng sau sô phải có chữ f hoặc F => số thực mặc định là kiểu double, default vaule = 0.0
- boolean: true hoặc false
- char là kiểu kí tự.
- default value chỉ có tác dụng với instance variable và static variable thôi, không có tác dụng với local variable.
```


`What happens if we use the value that out of range of data type?`

`Answer: `Thường sẽ là lỗi biên dịch nếu như khai báo trần bình thường (byte a = 310), còn nếu ép kiểu thì thường sẽ bị đổi giá trị, ví dụ từ 130 mà sang kiểu byte thì là -126. (bù số)
